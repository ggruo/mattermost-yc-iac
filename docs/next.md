# После обязательного маршрута

1. **Object Storage:** приватный bucket, access keys, загрузка/скачивание объекта,
   стоимость хранения и запросов. Затем защищённый remote state с блокировкой,
   шифрованием и отдельным IAM — отдельная задача, не «просто положить state в S3».
2. **Lockbox:** хранение пароля, получение через отдельный service account,
   ротация и обновление приложения без печати секрета.
3. **Instance Groups:** две одинаковые VM, template, health check и rolling update;
   сравнить с Deployment, не смешивая эти механизмы в обязательном стенде.
4. **Production:** multi-zone PostgreSQL, deletion protection, восстановление в
   пределах RPO/RTO, несколько workers, workload identity, аутентификация приложения.

Каждое расширение требует отдельной сметы и своей очистки. Бюджет 5 000 ₽
рассчитан как цель обязательного курса, не включает эти расширения.
