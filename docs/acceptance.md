# Лист облачной приёмки

Локальный validate/lint не доказывает работоспособность облачной связки.
Копируйте этот файл в `.local/acceptance.md` и отмечайте только выполненное.
Не публикуйте ID секретов, пароли, токены и содержимое kubeconfig.

- [ ] Смета с резервом укладывается в оставшийся бюджет; квоты проверены.
- [ ] VM apply успешен, повторный plan пуст.
- [ ] SSH только с trusted CIDR; PostgreSQL без public IP.
- [ ] Два Ansible-запуска; во втором changed=0.
- [ ] HTTPS доверенный, readiness=200, заметка остаётся после restart.
- [ ] VM destroy удаляет VM, IP, диск, DB и A-запись.
- [ ] Образ amd64 опубликован по digest, секретов в слоях нет.
- [ ] Kubernetes apply успешен, worker Ready и без public IP.
- [ ] Schema Job выполнен, Pod Ready, запись сохраняется после удаления Pod.
- [ ] NLB отдаёт ответ и удаляется вместе с Service.
- [ ] Gwin v1.10.0 запускается; Gateway/Route Accepted, ALB backends здоровы.
- [ ] HTTP→HTTPS redirect и доверенный сертификат проверены.
- [ ] Helm upgrade и rollback выполнены.
- [ ] HPA получает метрики; PVC сохраняет файл после пересоздания Pod.
- [ ] Ошибки Secret/SG/backend диагностированы и исправлены.
- [ ] Backup восстановлен в отдельный private cluster; маркер найден.
- [ ] Restore-кластер удалён.
- [ ] Gateway/Service удалены до контроллера; ALB/NLB исчезли.
- [ ] Kubernetes destroy завершён; дисков, IP и gateway не осталось.
- [ ] Registry, сертификат, ручные DNS-записи, ключи и logs очищены.
- [ ] Итоговые расходы записаны после обновления Billing.

Дата, версии, длительность ресурсов, фактическая сумма: заполнить при прохождении.
